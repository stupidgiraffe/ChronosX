# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please do not report security-sensitive findings in a public GitHub issue. Use GitHub's private security advisory flow for this repository, or contact the repository owner privately with:

- a concise impact summary;
- affected ChronosX version and framework/API version;
- reproduction steps using a non-sensitive test application;
- any suggested remediation.

Do not include credentials, production tokens, personal data, or proprietary app binaries. We will acknowledge a valid report, investigate it, and coordinate disclosure once a fix or mitigation is available.

## Scope notes

ChronosX intentionally hooks time APIs in explicitly selected third-party application processes. Findings that demonstrate or require targeting system processes, bypassing framework authorization, or extracting data from unrelated applications are outside the project's intended use and should not be developed as features.
